# ZenFlow Yoga Studio · Landing page

Proyecto académico de **Marketing Digital II** (laboratorio aplicado).
Landing page estática en HTML5 + CSS3 para el caso transversal ZenFlow Yoga Studio
(dirección de arte «Pausa Urbana»).

**Promesa:** «Empieza desde cero, sin presión y a tu propio ritmo».

## Avisos

- El formulario es una **demostración**: el botón es `type="button"` y no envía ni guarda datos.
- Las imágenes son **ilustraciones conceptuales**; no representan el estudio real.
- No se incluyen horarios, precios, testimonios ni direcciones exactas no verificadas.
